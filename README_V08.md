# MoviCerca v0.8 — corrección de mapa móvil

- Se sustituyó el servicio de imágenes Esri por OpenStreetMap estándar.
- Se añadió la selección **Fondo del mapa → Solo estaciones**, que desactiva mosaicos externos si aparecieran imágenes inesperadas.
- Los marcadores, GPS, búsqueda de lugares y estaciones disponibles se conservan de v0.7.
- La carga de mapas de terceros depende de internet y sus condiciones de uso. El mapa base no es publicidad controlada por MoviCerca; no se ha podido confirmar la causa exacta del contenido de colores del proveedor anterior.
- Se incrementó la clave de caché para facilitar la actualización en GitHub Pages. En Safari, cerrar la PWA y abrir la URL original en pestaña privada puede ayudar a comparar versiones.
- Para publicar, subir el contenido de esta carpeta en la raíz del repositorio y confirmar los cambios.
- Las estaciones siguen siendo cobertura parcial, con consulta externa a datos públicos donde la fuente responde.
